# g1 Project: Spectroscopy as a Probe of Spacetime Foam

## Project Overview
This project develops spectroscopic tests of quantum-gravitational spacetime foam using arrival-time jitter in light from distant sources. The research combines GRB spectroscopy (particularly GRB 221009A's MeV emission line) and CMB observations to constrain foam parameters.

## Key Research Topics
- Spacetime foam and quantum gravity phenomenology
- GRB 221009A spectroscopy and MeV emission features
- CMB spectral distortions from foam effects
- Temporal coherence ($g^{(1)}$) modifications by quantum gravity
- Fisher analysis of foam parameter constraints
