# g2 Project: Siegert Relation Violation as a Probe of Spacetime Foam

## Project Overview
This project demonstrates how quantum-gravitational spacetime foam violates the Siegert relation for temporal coherence. The work uses second-order coherence ($g^{(2)}$) as a complementary probe to first-order coherence ($g^{(1)}$) to test foam models, particularly focusing on strongly lensed and extended sources.

## Key Research Topics
- Spacetime foam and quantum gravity phenomenology
- Siegert relation and temporal coherence violation
- Second-order temporal coherence ($g^{(2)}$) in quantum optics
- Foam effects on different source types (point vs. extended, lensed sources)
- Quantum gravity observational constraints and systematic errors
